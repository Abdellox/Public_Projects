# Security Policy

## Supported versions

CompanyOS is a static site. Only the latest version on `main` is supported.

## Reporting a vulnerability

If you discover a security vulnerability (e.g., XSS via content injection, dependency vulnerability), please report it responsibly:

- Open a [security advisory](https://github.com/Abdellox/Public_Projects/security/advisories) if available, or
- Contact the maintainer directly instead of opening a public issue

Please include steps to reproduce and affected files. We aim to respond within 72 hours.
