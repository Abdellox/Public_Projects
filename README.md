# Public Projects

A collection of open-source projects by [@Abdellox](https://github.com/Abdellox). Each project lives in its own folder and is independent — pick one, dive into its README, and contribute.

| Project | Description | Tech |
| ------- | ----------- | ---- |
| [BlazePDF](./BlazePDF) | Lightweight, modern PDF reader for Windows with dark mode, auto-scroll, and text-to-speech | Python |
| [MiracleMind](./MiracleMind) | Economic Mindset Academy — research-based educational platform on the mindsets behind China & USA's success | HTML / CSS / JS |
| [OSSRadar](./OSSRadar) | Discover GitHub projects you can contribute to — live `good first issue` / `help wanted` feed + trending repositories | Next.js · TypeScript · Tailwind |

## Contributing

Every folder is a self-contained project with its own setup instructions, license, and contribution guide. A great place to start is **[OSSRadar](./OSSRadar)** — it was built to be a friendly on-ramp into open source:

1. Browse its [good first tasks](./OSSRadar/CONTRIBUTING.md#good-first-tasks)
2. Open an issue using the templates above
3. Send a pull request (keep it inside your project's folder)
