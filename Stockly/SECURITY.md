# Security policy

## Supported versions

Stockly's front end is a static site; only the latest `main` branch is supported.

| Version | Supported |
| ------- | --------- |
| latest `main` | ✅ |

## Reporting a vulnerability

If you discover a security issue, please **do not open a public issue**. Instead:

1. Contact the maintainer privately via [GitHub](https://github.com/Abdellox).
2. Include steps to reproduce, affected files/pages, and any proof-of-concept.
3. You'll receive an acknowledgment within 72 hours.

We aim to triage quickly given the project's small surface area — there is no backend here, so the most relevant concerns are XSS via rendered content and dependency vulnerabilities.

Thank you for helping keep Stockly and its users safe.
