# Contributing to Awesome AI Coding

Thank you for your interest in contributing! This project thrives on community contributions.

## How to Contribute

### Adding an MCP Server

1. Fork the repository
2. Add your MCP server to the appropriate section in `README.md`
3. Follow this format:
   ```markdown
   | [name](https://github.com/username/repo) | Stars | Description |
   ```
4. Submit a Pull Request

### Adding an Agent Config

1. Create a new file in `configs/` directory
2. Name it `{agent}-config.json`
3. Include clear comments explaining each setting
4. Submit a Pull Request

### Adding a Workflow/Skill

1. Add to the Skills & Workflows section in `README.md`
2. Include:
   - Name and description
   - Which agent it works with
   - Step-by-step usage instructions

### Adding a Tip or Trick

1. Add to the Tips & Tricks section
2. Keep it concise and actionable
3. Include any relevant links

## PR Guidelines

- One contribution per PR when possible
- Use descriptive PR titles
- Link to the original project when adding MCP servers
- Ensure all links work before submitting
- Follow the existing format/style

## Code of Conduct

- Be respectful and constructive
- Focus on helpfulness, not criticism
- Welcome newcomers and help them learn

## Questions?

Open an issue with the `question` label.
